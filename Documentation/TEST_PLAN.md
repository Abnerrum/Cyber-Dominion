# Plano de testes

## Testes no Unity Editor

- Abrir o projeto sem erros de compilação.
- Confirmar a criação automática da cena `CyberDominion`.
- Iniciar e continuar uma partida.
- Construir cada edifício em uma célula livre.
- Bloquear construção sobre uma célula ocupada.
- Impedir compra sem recursos suficientes.
- Coletar e produzir recursos.
- Salvar, fechar o Play Mode e carregar a partida.
- Iniciar as três missões.
- Validar vitória, derrota e retirada.
- Pausar e retornar ao menu.

## Limitação desta entrega

O ambiente automatizado utilizado para preparar o projeto não possui o Unity Editor. Os arquivos foram validados estruturalmente, mas o teste final em Play Mode deve ser executado após abrir o projeto no Unity 2022.3 LTS.
