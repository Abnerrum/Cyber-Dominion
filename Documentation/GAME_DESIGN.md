# Documento de design — Cyber Dominion

## Visão

Cyber Dominion é um jogo 2D de construção de base e batalhas estratégicas em um futuro no qual inteligências artificiais disputam energia, metais e territórios.

## Ciclo principal

1. Construir edifícios na base.
2. Produzir e coletar recursos.
3. Criar capacidade militar com centros de treinamento.
4. Iniciar uma missão.
5. Vencer unidades corrompidas e receber recompensas.
6. Ampliar a base e avançar para missões mais difíceis.

## Edifícios

| Edifício | Função |
| --- | --- |
| Quartel-general | Produz créditos e representa o centro da base. |
| Usina | Produz energia. |
| Mina | Produz metais. |
| Centro de treinamento | Adiciona tropas às batalhas. |
| Laboratório | Base para o futuro sistema de tecnologias. |
