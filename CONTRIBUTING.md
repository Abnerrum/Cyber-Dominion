# Como contribuir

1. Crie um fork do projeto.
2. Abra uma branch a partir de `main`.
3. Faça alterações pequenas e bem descritas.
4. Teste o projeto na versão Unity indicada.
5. Abra um Pull Request explicando o objetivo e os testes realizados.

Use mensagens de commit no padrão Conventional Commits, como `feat: add unit upgrade system`.
